# 测试报告模板

## 使用说明
- 本模板适用于：功能测试报告、回归测试报告、UAT 测试报告、性能测试报告
- 填写时请删除说明性文字，保留实际数据
- 所有缺陷统计需与缺陷管理系统 (Jira/GitHub Issues) 保持一致
- 报告完成后需经 QA Lead 审核、PM 确认方可归档

### 3.2 入口/出口标准
#### 入口标准 (Test Readiness)
- [ ] 需求基线冻结，验收标准确认
- [ ] 测试环境部署完成，冒烟测试通过
- [ ] 测试数据准备就绪 (含边界/异常数据)
- [ ] 测试工具/脚本/账号配置完成
- [ ] 相关文档 (API 文档、测试用例) 版本对齐

#### 出口标准 (Definition of Done)
- [ ] 所有 P0/P1 测试用例 100% 执行并通过
- [ ] P2 测试用例执行率 ≥ 90%，通过率 ≥ 95%
- [ ] 所有 P0/P1 缺陷已修复并验证通过
- [ ] P2 缺陷修复率 ≥ 80%，剩余已评估风险
- [ ] 性能/安全/兼容性专项测试达标
- [ ] 回归测试通过，无新增回归缺陷
- [ ] 测试报告、缺陷报告、自动化脚本归档完成
