# 验收标准

## 概述
本文档定义抖音电商数据监控平台各功能模块的验收标准，作为 UAT（用户验收测试）和版本发布的判定依据。

---

## 1. 通用验收标准

### 1.1 性能指标
| 指标 | 要求 | 测试方法 |
|------|------|----------|
| 页面首屏加载 (LCP) | < 2.5s | Lighthouse / Web Vitals |
| 交互响应 (FID/INP) | < 100ms | 真机测试 |
| 视觉稳定性 (CLS) | < 0.1 | Lighthouse |
| API 响应时间 (P95) | < 500ms | Load Test (100 并发) |
| API 成功率 | > 99.9% | 持续监控 |
| 同步任务成功率 | > 99.5% | 日志统计 |

### 1.2 兼容性
| 维度 | 支持范围 | 备注 |
|------|---------|------|
| 浏览器 | Chrome 100+, Edge 100+, Firefox 100+, Safari 15+ | 覆盖 95%+ 用户 |
| 分辨率 | 1366x768 以上，响应式适配 | 最小宽度 1200px |
| 语言 | 中文简体 (zh-CN) | 预留 i18n 扩展 |

### 1.3 安全性
| 要求 | 验收方式 |
|------|----------|
| HTTPS 强制 | 全站 TLS 1.2+，HSTS 开启 |
| 认证鉴权 | JWT + Redis 会话，Token 自动刷新 |
| 权限控制 | RBAC 矩阵，API 级别鉴权 |
| 敏感数据 | Cookie/Token 不记录日志，脱敏展示 |
| XSS 防护 | CSP 策略，输入输出编码 |
| CSRF 防护 | SameSite Cookie + CSRF Token |

### 1.4 可用性
| 要求 | 验收方式 |
|------|----------|
| 无障碍 | WCAG 2.1 AA 级（颜色对比度、键盘导航、ARIA） |
| 错误提示 | 友好的错误页面，操作引导明确 |
| 加载状态 | Skeleton/Spinner，无白屏闪烁 |
| 空状态 | 空数据引导图文案、操作入口 |

## 3. 非功能验收标准

### 3.1 部署运维
| 项目 | 标准 | 验收方式 |
|------|------|----------|
| Docker 镜像大小 | Frontend < 200MB, Backend < 500MB | `docker images` |
| 启动时间 | 服务就绪 < 30s | Systemd 启动日志 |
| 滚动部署 | 零停机，旧版本优雅下线 | 蓝绿/滚动部署演练 |
| 回滚时间 | < 5 分钟 | 回滚演练记录 |
| 日志规范 | JSON 格式，含 trace_id、span_id | 日志样例审查 |
| 监控覆盖 | 核心指标 100% 有告警规则 | Grafana 面板清单 |

### 3.2 数据质量
| 项目 | 标准 | 验收方式 |
|------|------|----------|
| 同步延迟 | 全量同步 < 30min，增量 < 5min | 任务日志统计 |
| 数据准确性 | 关键指标与官方后台误差 < 1% | 抽样对账 |
| 数据完整性 | 无丢单、无重复订单 | 唯一键约束 + 定期核对 |
| 历史数据保留 | 明细 1 年，聚合 3 年 | 存储策略文档 |

## 4. UAT 验收流程

### 4.1 验收准入
- [ ] 所有 P0/P1 缺陷已修复并验证
- [ ] 测试环境数据已准备（含边界数据）
- [ ] 验收测试用例已评审通过
- [ ] 相关文档（用户手册、API 文档）已更新

### 4.2 验收执行
| 角色 | 职责 |
|------|------|
| 业务方代表 | 执行业务场景用例，确认功能符合预期 |
| QA 工程师 | 执行非功能用例，记录缺陷 |
| PM | 组织验收会议，裁决争议缺陷 |
| Tech Lead | 技术风险评估，性能基线确认 |

### 4.3 验收通过标准
- [ ] 所有 P0 用例 100% 通过
- [ ] P1 用例通过率 ≥ 95%
- [ ] 无未解决的 P0/P1 缺陷
- [ ] 性能基线达标
- [ ] 安全扫描无高危漏洞
- [ ] 业务方代表签字确认

### 4.4 验收交付物
- [ ] UAT 测试报告
- [ ] 缺陷清单及处理记录
- [ ] 性能测试报告
- [ ] 安全扫描报告
- [ ] 部署运维手册
- [ ] 用户操作手册

## 5. 版本发布清单

### 5.1 发布前检查
- [ ] 代码合入主分支，Tag 打版本号
- [ ] CHANGELOG 更新
- [ ] Docker 镜像构建推送至仓库
- [ ] 数据库迁移脚本验证（回滚脚本准备）
- [ ] 配置变更记录（环境变量、Feature Flag）
- [ ] 通知相关方（运维、业务、监控）

### 5.2 发布后验证
- [ ] 健康检查通过
- [ ] 核心业务流程冒烟测试
- [ ] 监控大盘无异常告警
- [ ] 日志错误率 < 0.1%
- [ ] 用户反馈渠道畅通

### 5.3 回滚触发条件
- 核心接口错误率 > 5% 持续 5 分钟
- 数据同步任务连续 3 次失败
- 用户投诉量异常激增
- 安全事件触发
