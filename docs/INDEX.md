## 文档维护规范
1. **命名**：统一使用 `kebab-case.md`，目录使用数字前缀表示顺序（如 `3_deployment`）。
2. **更新**：每次重大架构、部署、安全变更后，必须同步更新对应文档并在变更记录中登记日期、版本、内容。
3. **链接**：跨文档引用请使用相对路径，确保在 GitHub/GitLab 及本地均可跳转。
4. **归档**：过期或已废弃的文档移至 `archive/` 目录，并在索引中标注。
