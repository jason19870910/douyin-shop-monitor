## 项目概述摘要

抖音电商数据监控平台是一个旨在为抖音电商店铺提供统一数据监控与告警手段的系统，帮助运营决策及时、异常及时发现。

### 核心目标
- 构建稳健、可维护的监控系统
- 提供商品、订单、创作者等数据的实时查询、可视化与异常告警
- 支持每日自动抓取

### 目标受众
- 抖音店铺运营人员
- 业务分析师
- 技术运维团队
