## 前端设计概览

抖音电商数据监控平台的前端设计包括：

1. **技术栈**
   - React 18 + Vite 5.x
   - TypeScript 严格模式
   - Ant Design 5.x UI组件库
   - Recharts 2.x 数据可视化库

2. **架构设计**
   - 模块化组件结构
   - 状态管理方案
   - 路由设计
   - 主题系统（浅色主题，2026-09-21 统一）

3. **页面布局**
   - 统一的页面结构（PageContainer、PageHeader）
   - 响应式设计
   - 导航和侧边栏

4. **组件设计**
   - 可复用的业务组件
   - 数据展示组件（表格、卡片、图表）
   - 表单组件
   - 提示和反馈组件

5. **样式和主题**
   - CSS变量系统
   - 响应式断点
   - 浅色主题适配（2026-09-21 统一）
   - 组件样式覆盖

6. **性能优化**
   - 代码分割
   - 懒加载
   - 记忆化计算
   - 虚拟滚动（长列表）

详细信息请参考 [`../FRONTEND_DESIGN.md`](../FRONTEND_DESIGN.md)。
