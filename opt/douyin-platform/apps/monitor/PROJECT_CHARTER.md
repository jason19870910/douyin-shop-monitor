# 项目章程 (Project Charter)

## 背景
- 抖音电商店铺缺乏统一的数据监控与告警系统，导致运营决策滞后、异常难以及时发现。

## 目标
- 构建一套可扩展、可靠的监控平台，提供商品、订单、创作者等关键数据的实时查询、可视化展示与异常告警。
- 支持每日自动抓取，提供 API 供内部系统与前端调用。

## 范围
- **内部系统**：提供统一的 RESTful API（详见 INTERNAL-API-SPEC.md）。
- **外部接口**：对接抖音电商后台的 6 大外部 API（详见 EXTERNAL-API-SPEC.md）。
- **前端**：React + Ant Design 实现 Dashboard、列表、告警配置页面。

## 关键成功因素
- 稳定获取动态签名参数（`a_bogus`、`msToken`、`verifyFp`、`fp`）并保持 Cookie 最新。
- 合理的限流与重试策略，防止因频率限制导致的数据缺失。
- 完整的监控告警（邮件、企业微信）。
