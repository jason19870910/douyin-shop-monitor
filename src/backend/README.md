# 后端服务

本文档提供后端服务的详细信息。

- API 规范：请参见 [API 规范](../docs/INTERNAL-API-SPEC.md)
- 主要组件：
  - Flask 应用入口：`app.py`
  - API 路由：`blueprints/` 目录
  - 业务服务：`services/` 目录
  - 数据库迁移：`migrations/` 目录
  - 辅助工具：`tools/` 目录
  - 工具函数：`utils/` 目录
  - 配置：`config/` 目录
  - 中间件：`middleware/` 目录
